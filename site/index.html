One loop, from sandbox to cheaper model

  1. Run

    Each agent session boots in its own Firecracker microVM in about 2.7 s. Every agent and subagent gets a SPIFFE identity.

  2. Control

    One gateway sees every model call, tool call and connection, decides it with Cedar policy, and can freeze, cut or kill any branch by name.

  3. Trace

    Every event lands in a hash-chained store, reconciled against the gateway's own counters, so completeness is measured.

  4. Retrain

    Runs are labelled by the benchmark's reward and an open-weight judge. Only passed runs, token-exact, train a LoRA on the open model.

  5. Score

    Held-out, user-disjoint tasks, four trials each, paired bootstrap intervals, and the frontier model on the same scaffold.
