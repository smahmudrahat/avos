Avos runs every AI agent in its own microVM with its own identity. Any agent or subagent can be stopped by name in milliseconds, every action is traced, and the passed runs retrain a small open model that does the same work for a fraction of the price.

What we measured

The approach

  1. RunEach agent session boots in its own Firecracker microVM in about 2.8 s. Every agent and subagent gets a SPIFFE identity, so every action has an owner.
  2. ControlOne gateway sees every model call, tool call and network connection, decides it with Cedar policy, and can freeze or cut any branch by name without touching its siblings.
  3. TraceEvery event lands in a hash-chained store, reconciled against the gateway's own counters, so completeness is measured, not assumed.
  4. Label and retrainRuns are labelled by the benchmark's reward and an open-weight judge. Only passed runs, token-exact to what the model saw, train a LoRA on the open model.
  5. ScoreHeld-out, user-disjoint tasks, four trials each, paired bootstrap intervals, and the frontier model run through the same scaffold and simulator.

What we proved, and what we run next

Proved

    Next run

    • A harder, larger held-out set. τ²-bench retail cannot separate a 9B from Opus: even the untrained 9B ties. We are moving to 200+ held-out tasks across domains, where the frontier model measurably leads, so every retraining round shows up in the score.
    • More rounds of retraining. The loop is built and repeatable: collect traces, keep the passed runs, retrain, re-score. Each round costs a few GPU-hours.
    • Simulator fidelity checks. A judge flags trials where the simulated user broke its script, so failures are charged to the right side.
