Why it is built this way

  1. Result firstThe outcome is on screen in the first second. The rest shows how you got it.
  2. Readable with sound offFeeds autoplay muted, so the captions carry the whole story.
  3. One live momentThe stop click: one node freezes while its siblings keep counting.
  4. One screen, no cutsAll panels stay on screen, so it reads as working software, not slides.
  5. Proof experts can checkBenchmark, held-out split and pass^4 are named on screen; the repo has the eval. Cut 0:14–0:26 as a short loop for replies.
